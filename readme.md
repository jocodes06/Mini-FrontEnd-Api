## URL API
https://jsonplaceholder.typicode.com/posts

## Functionalitati
- GET: incarca lista de postari
- POST: creeaza o postare în format JSON
- Cautare dupa titlu
- Mesaje pentru încarcare lista goala si erori

## CORS :
Nu a trebuit sa fac nimic special, serverul jsonplaceholder
permite deja cereri de pe alte domenii iar eu rulez doar
fisiere statice html css js.

## Status codes
- 200: GET reusit.
- 201: POST reusit
- 4xx: tratat în cod `!response.ok`, eroare de client, mesaj afisat utilizatorului
- Eroare de retea : mesaj generic

## Rulare
Deschide index.html sau foloseste Live Server
in Visual Studio Code.
